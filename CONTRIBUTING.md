# Contributing to homebrew-beacon

Thank you for your interest in contributing!

## Getting Started

1. Fork this repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/homebrew-beacon.git`
3. Create a feature branch: `git checkout -b my-feature`
4. Make your changes
5. Push to your branch: `git push origin my-feature`
6. Open a Pull Request

## Homebrew Tap Guidelines

- Follow Homebrew formula conventions
- Test formulas with `brew audit` and `brew test`
- Keep Cask definitions up to date with upstream releases
- Use `brew style` to check formatting

## Pull Request Process

- Reference any related issues
- Include a clear description of changes
- Ensure `brew audit` passes for modified formulas
- One formula per PR is preferred

## Reporting Issues

- Use the GitHub Issues tab
- Include your OS version and Homebrew version
- Describe expected vs actual behavior
